MyNOS, running in your browser

Source Manual Releases

MyNOS is an operating system for 32-bit PCs: a microkernel in C, and above it the file systems, the drivers, the shell and the windows as processes, most of them in OCaml. Here it runs on v86, a PC emulated in JavaScript and WebAssembly. Click on the screen to type. Try help, ls /disk, ocaml, trace ls /disk, then gui: the graphical session, and its Tour, which explains how an operating system works while it runs.

Here there is no network, and so no language models or agent; nothing you save is kept. For the full experience, download the release and run it with QEMU. Starting...
