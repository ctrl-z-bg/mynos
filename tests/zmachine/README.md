# Czech, a test of Z-machine interpreters

`czech.z5` is Amir Karger's Czech 0.8 (2003), the "Comprehensive
Z-machine Emulation CHecker", from the IF Archive
(`if-archive/infocom/interpreters/tools/czech_0_8.zip`); `README.txt` is
its own, with its licence, unchanged. The seventh boot of
`tools/run-tests.sh` installs the package `zmachine` and runs it:
"Passed: 406, Failed: 0".
